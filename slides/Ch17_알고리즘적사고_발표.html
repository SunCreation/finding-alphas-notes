LPF 저역통과 · 고주파 감쇠 HPF 고역통과 · 저주파 감쇠 BPF 대역통과 · 특정 대역만 BSF 대역저지 · 특정 대역 제거
GAIN

§퀀트의 필터 상식

▲ SMA·EMA
사실 저역통과 필터다가장 대중적인 스무딩 도구가 곧 LPF — 별게 아니라 필터였다

BUTTER

최적화와 손실함수 설계

OPTIMIZATION · LOSS DESIGN

§최적화의 심장

정의
실현가능해 집합에서 최적해 고르기실현가능성 = 설계 사양·운용 요건·프로세스 한계 / 최적성 = 손실(비용)함수 최소화로 정량화
KEY
손실함수 선택이 효과적/비효과적 최적화를 가른다문제의 성질과 데이터셋에 의존 — 절반은 “무엇을 벌할지” 정하는 것

§L1 vs L2 — 정반대 성격

L2 놈 — Σe²L1 놈 — Σ|e|
큰 오차이차 벌금 → 이상치에 취약강건(robust)
전체 성능데이터 전반에 고름다수 0 · 일부 매우 큼 → 최악 성능 불리
안정성안정적불안정할 수 있음
Huber — 작은 오차엔 L2, 큰 오차엔 L1:
L(e) = ½e² (|e|≤δ)  /  δ(|e|−½δ) (|e|>δ)
# L1의 강건성 + L2의 안정성 — 실전에서 둘 다 능가하는 경우 多

§정규화 — OLS의 약점 치료RIDGE · LASSO · ELASTIC NET

# 고전 회귀 — 오차에 L2 벌점. 계수 폭발에 취약
# (특히 상관 높은 예측변수들에서)

Ridge (티호노프): min ‖y−Xβ‖² + λ‖β‖₂²
# 큰 계수 억제 — 안정성 확보

Lasso: min ‖y−Xβ‖² + λ‖β‖₁
# 희소성 → 유용한 변수 부분집합만 생존 (변수선택)

Elastic Net: L1 + L2 동시 적용
# 성능·강건성·희소성·안정성 절충 — 두 문제 공존 시
요점
손실함수 성질을 알면 창의적 응용이 가능일상 퀀트 문제에 맞는 목적함수를 직접 설계하는 것이 실력
▲ 실전
라쏘 = 검증된 변수선택 전략여러 실제 응용에서 특징 선택 기법으로 성공

§차원 축소FEATURE EXTRACTION

PCA
주성분 분석 — 비모수 축소의 대표주자통계적 위험모형 · 주성분 포트폴리오(자산배분) · 군집화 — 대부분의 변동을 설명하는 소수 특징으로 재표현
▲ sPCA

§축소 추정량SHRINKAGE

개념

▲ LW
Ledoit–Wolf(2004) — 공분산 추정의 클래식표본 공분산을 상수상관 모형 쪽으로 축소 → 순진한 추정 기반 포트폴리오를 능가 (자산배분·리스크관리) — 시간의 시험 통과

PARAMETER OPTIMIZATION · CONCLUSION

§파라미터의 3단 진화

정적
STATIC
고정 파라미터 — 기본값움직이는 표적(moving target) 반영 못 함. 최적 파라미터는 문제 특성의 함수 — 정적·획일적일 이유가 없다
동적
DYNAMIC
시간·단면 특성의 함수로 변동예 — 뉴스 매매에서 대형주는 관심↑·정보효율↑ → 보유기간을 시가총액 함수로 조절
자기적응
ADAPTIVE
피드백 루프를 닫는다정적·동적 모두 표본 밖 성과를 안 씀 → 실현 성과로 튜닝을 알고리즘 내부에 내장, 실행 중 자동 조정
▼ 핵심
표본 밖 성능에 파라미터 선택이 결정적같은 모형도 파라미터화 전략에 따라 생사가 갈림

§장의 논리 흐름

1
툴킷 — 디지털 필터노이즈 감쇠·증폭의 수학, 스무딩·분해의 재해석
2
목적함수 — L1/L2 · 정규화 · Huber무엇을 벌할지 정하는 것이 최적화의 절반
3
현실 대응 — 편향-분산 · 차원축소 · 축소추정불완전한 데이터 환경에서 학습에게 기회 주기
4
살아있는 파라미터 — 동적 · 자기적응표적이 움직이니 무기도 움직여야

§에이전트 관점 · 비판적 시각
