§3가지 문제 유형

REG
회귀 Regression — Y = f(X)양적 X로 양적 Y 추정 — 수익률·주가 예측이 대표 사례
CLS
분류 Classification — 질적(범주형) Y양적 입력으로 범주 판정 — 다음 달 상승/하락 이진 예측
CLU
군집화 Cauterization — 라벨 없는 X비슷한 특징끼리 묶기 — 정답을 모르는 채 탐색하는 과제
▲ 지도
정답(ground-truth) 예시로 학습과거 정답 세트를 제공 — 주가 예측에 적합
▼ 비지도
정답 없이 품질 기준만으로 탐색군집화가 여기 속함 — 포트폴리오 편입 종목 선정이 대표 적용

통계 모형과 SVM

STATISTICAL MODELS · SVM

§통계 모형BAYES · LDA · HMM · LOGISTIC

▲ 강점
단순 문제에 유용 · 구현 쉬움 · 결측치에 둔감고정밀 분류·예측이 꼭 필요 없는 과제에 적합
▼ 약점
각 방법이 특정 데이터 모형을 가정가정이 어긋나면 성능 급락
HMM
은닉 마르코프 모형 — 추세 분석의 대표 응용① 은닉 마르코프 연쇄(시간 변동) + ② 관측 과정(스펙트럼 변동) 합성. 관측 序列 → 은닉 상태 복원 → 장기분포 대비 현재 추세 위치 판별

§SVM/SVR을 알파에 쓰는 법

SVR
서포트 벡터 회귀로 수익률 예측마진 폭 조절로 금융 데이터의 변동성 변화 모사
▲ 비대칭
비대칭 마진 → 다운사이드 리스크 축소상·하방 마진을 다르게 잡아 하방 오차에 더 민감하게 학습
▼ 단점
학습 시간 과다 · 병렬 컴퓨팅 부적합현대 대규모 알고리즘에는 발목

§마진 최대화 — 구조적 위험 최소화

R(θ) = R_emp(θ) + λ · R_reg(θ)
# 경험적 오차(훈련 적합도) + 정규화 항(복잡도 통제)
# 퍼셉트론 — 앞 항만 최소화 → 과적합
# SVM — 뒷 항이 표본 밖 보존을 담보
두 범주가 겹치지 않는 공간에서 훈련 점과 경계 사이 거리를 최대화하는 초평면. 견고한 이론 기반과 다양한 변형이 강점.

§신경망 NNNEURAL NETS

본질
알고리즘이 아니라 “알고리즘을 표현하는 방식”뉴런 구조가 아니라 연결 구조와 학습법이 핵심 — 임의 과제용 설계 이론은 아직 없음
▲ 학습
역전파(backpropagation)충분한 컴퓨팅 파워만 있으면 매우 효율적 — 체스·바둑·신용등급·사기탐지
▼ 한계
이론 부재 · 내부 불투명(블랙박스)내부 논리 해석이 어려워 발목

§앙상블RANDOM FOREST · ADABOOST

원리
약한(weak) 분류기·예측기 다수를 결합더 강한 분류·더 정밀한 예측 획득
RF
랜덤포레스트 = 트리들의 투표단순 결정트리 다수 생성 → 새 사례에 투표로 최종 판정
BOOST
AdaBoost = 정확도 >50% 약분류기의 가중 결합Real AdaBoost는 역추적으로 불리한 약분류기 제거 — 오류율↓·특징집합↓, 학습시간 약 5배

§딥러닝DEEP LEARNING

어원
Hinton의 RBM(제한 볼츠만 머신)다층 NN 사전학습용 비지도 방법 — 역전파 개선편이라는 강증거는 없음
▼ RNN
기울기 소실 문제단계별 가중치 변화가 너무 작아지거나 커져 학습 불안정 — 자연어 처리 계열
▲ CNN
합성곱 신경망 — 요즘 “딥러닝”의 대명사후쿠시마(neocognitron) + LeCun(역전파 변형) · 학습 리소스는 많이 필요하나 병렬화 유리 · 시계열 최고 성적은 DBN(Kuremoto 2014)

§퍼지 논리FUZZY LOGIC

개념
예/아니오 이분법 사이 “회색조” 허용“아마 참”·“불확정” — 부분 정의 명제로 추론
▲ 강점
정보 부족 상태의 의사결정 기제불명확한 추론 규칙 내장
확장
퍼지 전문가 시스템 · 하이브리드 NN신념도(degree of belief)에 따라 다양한 응답 — 금융 과정·시장 모형 연구로 관심 확대

§장의 논리 흐름

문제
알파 연구의 본질 = 미래 예측과거 설명이 아닌 예측 정확도가 목표 — 복잡 vs 단순 딜레마에서 출발
지도표
Figure 16.1 계보지도(통계·SVM·신경망·앙상블) / 비지도(군집화) / 퍼지 논리 / 딥러닝
선택
과제 특성에 맞는 도구 선택추세판별 HMM · 과적합 걱정 SVM/SVR · 표본 밖 성능 앙상블 · 대규모 병렬 CNN·DBN · 불확실성 퍼지
결론
ML은 선택이 아니라 필수 인프라이용 가능한 데이터 전체를 ML 없이 알파 구축에 소화하는 것은 불가능

§투자 에이전트 관점의 함의

▲ 1
예측기 파이프라인회귀(수익률 크기)·분류(방향)·군집(유니버스 선정)을 알파 생성기의 서로 다른 슬롯으로
▲ 2
SVR 비대칭 마진손실 회피 성향을 목적함수에 직접 반영 — 리스크 관리와 예측의 일체화
▲ 3
HMM 레짐 탐지관측 序列로 시장 국면을 상태 변수화 — 알파의 상황별 게이팅

§비판적 시각

▼ ①
“과거 정답”의 안정성 가정지도학습 라벨이 내일도 같은 의미라는 가정 — 레짐 변화에 취약
▼ ②
블랙박스 vs 해석가능성책도 NN 불투명성 인정 — 규제·리스크 관리상 해석 가능 모형이 요구되는 경우 많음
▼ ③
2019년 시점의 시야CNN·DBN이 최전선 — 이후 트랜스포머 계열 등장으로 실무 최전선은 이동
데이터는 현대 디지털 세계의 가장 귀중한 자원 — 그 전부를 활용하려면 머신러닝이 필수다. WWII 후 수요 폭발 → 1957 퍼셉트론 → 1960s SVM → 앙상블·딥러닝의 시대
